LDFC「池子投放面板」UI 候选（5 版）

用法：按住多选后的悬浮球拖动 → 球变形成投放面板 → 拖到某个池子上松手即移入。每版都把「⭐ 感兴趣」画成了当前悬停高亮状态。 池子图标统一无着色线性图标；球右上角「3」是多选计数。

1半圆扇形最像现在的球

3
球不动，只向上升出五个落点（贴底时就地展开）
  • 好：仍是「那个球」，镜头不跳；拖动行程最短，松手前手指几乎不用移动。
  • 难：五格只有图标，头几次要认；贴屏幕上方时半圆要整圈翻成朝下。

2横向胶囊条最好读

3
球贴左边 → 条向右长；球贴右边 → 条向左长，永不出屏
  • 好：一行五格，视线不来回跳；命中率高，键鼠和触屏都稳。
  • 难：仍是纯图标；条长约 280px，窄屏（<360px）要缩格或折两行。

4罗盘环最轻

平时只有五个点，悬停哪格才在哪里浮出名字
  • 好：占屏最小、最「苹果」；环形有节奏感，和球的圆呼应。
  • 难：44px 目标在触屏上偏小，手抖容易滑进隔壁；上下两个点会被行内容压住。

拖拽全程不变形、不跳位：把球原地换成一条等高列，
手指在哪一行松开就投进哪个池；右侧带现有条数
  • 好：命中率最高（整行 40px 可放）；有名称、有效量；动画最省事——只需高度展开，不用算方位。
  • 难：占纵向空间最多（约 250px），贴底时要整列翻上去；手感不如 1/4 那种「弹出」。
