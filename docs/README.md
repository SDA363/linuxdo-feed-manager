所有文档在移动前位于仓库根目录，移动后互相引用的文件名不变，因此文内 `LDFC-xxx.md`
这类裸文件名引用仍然有效（同目录）。

## 七、读文档时的注意事项

1. **版本号与测试数是当时快照。** 各轮报告里出现的 `0.3.0` / `0.4.0-rc.1` / `37` / `44` /
   `49` / `65` / `70` 都是撰写当时的数值，不代表当前状态。当前状态只以
   `LDFC-实现状态.md` 为准。
2. **`PASS` 的适用范围写在报告里。** 区分「本地 fixture 通过」「真实站点通过」
   「Android 模拟器通过」「真实手机未验证」，不要跨级引用。
3. **本目录不含代码。** 正式源码在 `../linuxdo-personal-feed-manager/`，
   自动化工具在 `../browser-lab/`，构建脚本在 `../tools/`。
